# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-12-01

### Added

- Initial release
- Tool calling extension for AshAgent
- `agent_tools` DSL for defining tools available to agents
- Support for Ash actions and Elixir functions as tools
- Tool templates for reusable tool definitions
- Result processors for managing tool output
